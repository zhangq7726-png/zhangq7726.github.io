# 霓虹疾驰 Neon Rush

[直接游玩](https://zhangq7726-png.github.io/zhangq7726.github.io/games/neon-rush/)

竖屏赛车跑酷：三车道避障、金币、氮气加速、三次碰撞机会、逐渐提速和本机最高分记录。

- 电脑：Enter 开始；← → 或 A / D 切换车道；空格释放氮气；P 暂停；M 切换音效。
- 手机：点击底部左右按钮，或在赛道上左右滑动；点击氮气按钮加速。
- 计分：行驶距离（米，取整）+ 金币 × 50。
- 氮气需 35 点能量，持续 2 秒；能量随时间恢复，金币额外补充能量。

`index.html` 为离线单文件版本，下载后可用浏览器打开；不依赖外部网络和服务。
`source/` 保存可继续编辑的 DSH Game Studio 游戏项目。使用 DSH Game Studio 的 `game_studio_build` 可重新构建。

开发验证：Chrome 竖屏自动试玩、开始与结算画面、键盘与触屏控制、碰撞结束与重开；无脚本错误及外部网络请求。

构建与模板来自 [DSH Game Studio](https://github.com/ZSeven-W/dsh-game-studio)，保留其 MIT 许可，见 `DSH-GAME-STUDIO-LICENSE.txt`。
